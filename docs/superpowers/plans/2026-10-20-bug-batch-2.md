### C. Lab finding reports inside the generated PDF — Notion 3ff425dd-…-4e5/8149
Size: medium, pdfWorker-led. Design under discussion (decisions below).
1. cph: make sure the snapshot carries the lab file keys as a list (today the `labFindings` string).
2. pdfWorker: download each key (storage-sdk), append after the case pages: PDF → import its pages (PDFBox); png/jpg → new page, scaled to fit, file name as caption; other types skipped. A bad/oversize/encrypted file is skipped and logged, never fails the job.
3. Tests: merge of PDF + image, corrupt file skipped, ordering, page count; visual check on a real case.
Decided: after all pages are rendered, if the case has lab files, put a line in the lab findings field saying the findings are attached below and append the files at the end; if none, leave the document untouched. Still open: caps (10 MB per file; max files/pages), image compression.
